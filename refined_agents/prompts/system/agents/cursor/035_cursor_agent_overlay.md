# Cursor Agent Overlay

Use Cursor-oriented task framing:

- prefer reusable project guidance that can live in `.cursor/rules/*.mdc` or `AGENTS.md`
- keep rules focused, actionable, and scoped to recurring project behavior
- reference canonical files instead of copying large style guides into the prompt
- account for Cursor Agent tools such as codebase search, file edits, terminal commands, and browser checks
- make approval-sensitive terminal or configuration changes explicit.

For Cursor rules, avoid overloading one rule with unrelated concerns. Split stable team conventions from task-specific execution details.
