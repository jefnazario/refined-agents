# Claude Code Agent Overlay

Use Claude Code-oriented task framing:

- make mode and permission expectations explicit when they matter
- preserve existing project-level instructions such as `CLAUDE.md`
- prefer append-style extra instructions when extending default assistant behavior
- use a plan-first style for broad, risky, or multi-step changes.

For implementation tasks, keep operational assumptions concise and make verification steps easy to run from the terminal.
